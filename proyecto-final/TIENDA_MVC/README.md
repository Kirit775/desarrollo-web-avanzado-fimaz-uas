# Tienda MVC - PHP

Tienda en línea con panel de administración hecha en PHP puro con el patrón MVC.

## Requisitos
- XAMPP con Apache y MySQL
- PHP 8

## Instalación
1. Copia la carpeta `TIENDA_MVC` en `C:/xampp/htdocs/`
2. Importa `database.sql` en phpMyAdmin
3. Abre `admin.php` en el navegador y copia el hash generado en la tabla `usuarios`

## Rutas
- `/TIENDA_MVC/catalogo` — catálogo público
- `/TIENDA_MVC/login` — acceso admin
- `/TIENDA_MVC/api/productos` — API REST en JSON
